# Fixed Scroll Requirements

## Purpose

Build a small native macOS menu bar utility that turns F1 and F3 into
predictable scrolling. Each accepted key press must emit the same pixel-based
scroll delta instead of Karabiner-Elements' speed-based, accelerated mouse-key
scrolling.

## User Workflow

1. The user builds and opens `FixedScroll.app`.
2. On first launch, the app explains through its menu that Accessibility
   permission is required and prompts macOS for that permission.
3. Once permission is granted, the menu status changes to active without the
   user having to restart the app manually.
4. Pressing F1 scrolls upward by the configured distance; pressing F3 scrolls
   downward by the same distance. Holding either key continues scrolling after
   the macOS key-repeat delay until release.
5. The user can select 280 px, 420 px, or 560 px from the menu. The default is
   420 px and the selection persists across launches.
6. The menu provides explicit test-up and test-down actions and a Quit action.

## Functional Requirements

- Run as a menu bar accessory without a Dock icon or main window.
- Listen globally for unmodified F1/F3 key events.
- Also listen for F13/F14 as reliable bridge keys from Karabiner-Elements:
  F13 scrolls down and F14 scrolls up. The bridge maps F1 to F14 and F3 to F13.
- Suppress handled key-down and key-up events so the original brightness,
  Mission Control, or function-key action does not also occur.
- Ignore Command, Control, Option, or Shift modified function keys and pass
  them through unchanged.
- Treat a quick physical press as one scroll action. Accept macOS auto-repeat
  key-down events so holding a supported key continues with the same fixed
  distance per event until release; use the user's system repeat delay and rate
  rather than adding an app-owned timer or acceleration curve.
- When a supported virtual-machine or remote-desktop client is frontmost, pass
  F1/F3/F13/F14 through unchanged. This applies to Parallels, VMware Fusion,
  VirtualBox, UTM, Microsoft Remote Desktop/Windows App, Citrix, AnyDesk,
  RustDesk, and TeamViewer bundle identifiers.
- Post one Core Graphics scroll-wheel event using pixel units and a constant
  signed delta.
- Scroll the UI under the mouse pointer, matching normal macOS wheel routing.
- Persist only the selected distance, using `UserDefaults`.
- Detect a disabled event tap and re-enable it.

## Permission and Failure Behavior

- Request macOS Accessibility permission on first launch. This is required for
  a global key event tap.
- If permission is absent, keep running, show a clear inactive status, disable
  test actions, and provide a menu action that opens the Accessibility privacy
  pane.
- Poll for a newly granted permission and install the event tap without a
  forced application restart when macOS allows it.
- If event-tap creation fails despite permission, remain inactive and log a
  concise diagnostic through the system log.
- Never require administrator privileges, network access, or third-party
  runtime dependencies.

## Consistency Boundary

The app guarantees that it emits the same pixel delta for every accepted key
press. Most AppKit, WebKit, and Chromium scroll views interpret this as a fixed
content displacement. Applications with custom scrolling, pagination, zoom,
or terminal line grids may reinterpret or quantize wheel events, so identical
visible displacement in every possible application is not technically
guaranteed by macOS event injection.

## Packaging and Compatibility

- Build with the installed Apple Swift toolchain and no package dependencies.
- Target macOS 13 or later on Apple silicon and Intel Macs.
- Produce an ad-hoc signed `FixedScroll.app` bundle under `dist/`.
- Include an importable Karabiner complex-modification rule that maps F1/F3 to
  F13/F14 for users whose top-row keys are configured as media keys. The rule
  must use the same virtual-machine and remote-desktop exclusions as the app so
  those clients receive the original F1/F3 events.
- Document that scroll-transforming utilities such as LinearMouse must bypass
  events generated by other applications to avoid reversing Fixed Scroll's
  output a second time.

## Non-Goals

- Smooth scrolling animation, momentum, or app-defined acceleration curves.
- Per-application distance profiles.
- Horizontal scrolling.
- Automatic installation into `/Applications` or automatic modification of
  the active Karabiner profile.
- Launch-at-login management in the first version.
